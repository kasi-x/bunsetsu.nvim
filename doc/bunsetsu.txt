1. 概要                                              *bunsetsu-overview*

bunsetsu.nvim は、日本語文章での移動を文節 (ぶんせつ) 単位にする Neovim
プラグインです。nvim-spider と flash.nvim の拡張として動作します。

TinySegmenter で学習した文節区切りモデル (knbc_bunsetu 等) を Lua 移植して
同梱しており、追加インストールなしでオフラインで文節分割できます。より高精度
が欲しい場合は Vibrato / Vaporetto (外部トークナイザ CLI) をバックエンドに
設定できます。

主な特徴:
- nvim-spider 拡張: customPatterns に境界関数を登録すると、w/b/e/ge が
  日本語上では文節移動・ASCII 上では nvim-spider の単語移動になります。
- flash.nvim 拡張: 事前計算した文節一覧を matcher に渡し、文節へラベルジャンプ。
- 文末移動: 日本語 (。！？…) と英語 (. ! ?) の文末を判定し、混在文書でも
  文末ずつ移動できます (間接引用の例外つき)。
- 一文モード (カーソル行のみ即時分割) と全文モード (バッファ全体を事前分割、
  編集時は変更行のみ再計算) を分離し、編集時のレスポンスを高速化。
- 品詞ごとのアンダーライン表示、カーソル下の語の原形・読み・品詞取得
  (Vibrato バックエンド + UniDic 辞書)。

2. インストール                                        *bunsetsu-install*

lazy.nvim: >lua
    {
        "kasi-x/bunsetsu.nvim",
        version = "v1.*",
        dependencies = { "chrisgrieser/nvim-spider", "folke/flash.nvim" },
        opts = {},
    }
<

:checkhealth bunsetsu で動作確認ができます。

3. 設定                                                  *bunsetsu-config*

設定は vim.g.bunsetsu_configuration にテーブルで渡します。

model            同梱 TinySegmenter バックエンドの文節区切りモデル名。
                 省略値: "knbc_bunsetu"
                 設定可能: "knbc_bunsetu" "wpci_bunsetu" "jeita" "rwcp"
splitpat         強制的に分節区切りを入れる文字のパターン。シンプルな文字
                 クラス '[...]' のみ解釈する (多バイト文字も可)。
                 一致した文字は前の文節に残り、直後が強制境界になる。
                 空文字列で無効化。解釈できないパターンは省略値に
                 フォールバックする。
                 省略値: "[?!、。]"
splitsep         :BunsetsuSplit の区切り文字列。
                 省略値: " "
debounce         全文キャッシュ無効化のデバウンス(ms)。
                 省略値: 50
vibrato          Vibrato バックエンドの設定テーブル。
                 - cmd: tokenize CLI のパス (省略値: "vibrato")
                 - dict: 辞書 (.dic.zst) のパス (空なら Vibrato 無効)
vaporetto        Vaporetto バックエンドの設定テーブル。
                 - cmd: predict CLI のパス (省略値: "predict")
                 - model: モデル (.model.zst) のパス
lemma            UniDic 辞書引きの設定テーブル。
                 - dict_path: surface<TAB>lemma<TAB>reading<TAB>pos の TSV
highlight        品詞ハイライトの設定テーブル。
                 - enabled: true で有効化 (省略値: false)

設定例: >lua
    vim.g.bunsetsu_configuration = {
        vibrato = {
            cmd = "/path/to/tokenize",
            dict = "/path/to/system.dic.zst",
        },
    }
<

================================================================================
4. nvim-spider 統合                                      *bunsetsu-spider*

nvim-spider の customPatterns に bunsetsu の境界関数を登録すると、w/b/e/ge
が日本語上では文節単位の移動になります (ASCII 上は nvim-spider の単語移動の
まま)。

>lua
    require("spider").setup({
        consistentOperatorPending = true,
        customPatterns = {
            -- 設定からバックエンドを自動選択する
            -- (vibrato 辞書 > vaporetto モデル > 同梱 TinySegmenter)
            patterns = { require("bunsetsu").pattern("bunsetsu") },
            overrideDefault = false,
        },
    })
<

mode は "word" (単語境界) または "bunsetsu" (助詞を結合して文節境界)。
バックエンドを明示したい場合は vibrato_pattern() / vaporetto_pattern() /
`bunsetsu._commands.spider` の pattern を直接登録する。

>lua
    require("bunsetsu").vibrato_pattern("bunsetsu")
    require("bunsetsu").vaporetto_pattern("bunsetsu")
<

================================================================================
5. バックエンド                                        *bunsetsu-backends*

TinySegmenter (既定)~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
同梱の TinySegmenter Lua 移植 + 文節区切りモデル 4 種
(knbc_bunsetu / wpci_bunsetu / jeita / rwcp) で分割します。
追加のインストールは不要です。

Vibrato~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Vibrato (https://github.com/daac-tools/vibrato) の tokenize CLI で
形態素解析 (単語分割 + 品詞 + 原形 + 読み) を行います。

>sh
    git clone https://github.com/daac-tools/vibrato
    cd vibrato
    cargo build --release -p tokenize
    # 実行ファイル: target/release/tokenize

    # 辞書は vibrato の Releases から入手できる (例: mecab-ipadic)
    wget https://github.com/daac-tools/vibrato/releases/download/v0.5.0/ipadic-mecab-2_7_0.tar.xz
    tar xf ipadic-mecab-2_7_0.tar.xz
<

>lua
    vim.g.bunsetsu_configuration = {
        vibrato = {
            cmd = "/path/to/vibrato/target/release/tokenize",
            dict = "/path/to/ipadic-mecab-2_7_0/system.dic.zst",
        },
    }
<

vibrato.dict を設定すると全文モード・品詞ハイライト・:BunsetsuSplit が
Vibrato を使うようになります。原形・読みは辞書出力に含まれるため、
bunsetsu.lemma_under_cursor() は UniDic 辞書 (lemma.dict_path) 無しで
動作します。

Vaporetto~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Vaporetto (https://github.com/daac-tools/vaporetto) の predict CLI を
文節境界の計算に使えます。MeCab の数十倍速い単語分割トークナイザです。

1. predict CLI をビルド:
>
    git clone https://github.com/daac-tools/vaporetto
    cd vaporetto
    cargo build --release -p predict
<
2. モデルを入手 (例: bccwj-suw+unidic_pos+pron):
>
    wget https://github.com/daac-tools/vaporetto-models/releases/download/v0.5.0/bccwj-suw+unidic_pos+pron.tar.xz
    tar xf bccwj-suw+unidic_pos+pron.tar.xz
<
3. 設定に登録:
>
    vim.g.bunsetsu_configuration = {
        vaporetto = {
            cmd = "/path/to/vaporetto/target/release/predict",
            model = "/path/to/bccwj-suw+unidic_pos+pron.model.zst",
        },
    }
<

6. flash.nvim 統合                                       *bunsetsu-flash*

事前計算した文節一覧を flash.nvim の matcher に渡し、文節へラベルジャンプ
できます。

>lua
    vim.keymap.set("n", "<leader>j", function()
        require("bunsetsu._commands.plugins.flash").jump()
    end, { desc = "Jump to bunsetsu" })
<

日本語の文節と ASCII の単語は同一の segment リストに載るため、混在文章でも
flash のラベルが正しく付きます。

7. 文末移動                                              *bunsetsu-sentence*

日本語 (。！？…) と英語 (. ! ? + 空白・行末) の文末を判定し、混在文書でも
文末ずつ移動できます。カーソルが文末の上にある場合は、それより後ろ (前) の
文末を探します。移動できたかどうかは戻り値 (boolean) で分かります。

>lua
    vim.keymap.set("n", ")", function()
        require("bunsetsu").next_sentence_end(vim.v.count1)
    end, { desc = "Next sentence end" })
    vim.keymap.set("n", "(", function()
        require("bunsetsu").prev_sentence_end(vim.v.count1)
    end, { desc = "Previous sentence end" })
<

文末の判定規則:
- 日本語: 。！？… が文末。直後の閉じ括弧・引用符 (」』） など) も文末に含む。
  …… や !! の連続は 1 文末にまとまる。
- 英語: . ! ? は直後に空白・行末が続く場合のみ文末。"3.14" や "U.S.A" は
  文末とみなさない。Stop." のように閉じ引用符を挟んだ場合も文末。
- 間接引用の例外: 「〜だ。」と言った のように、閉じ括弧の直後の文末が
  接続表現 (と言った / という / の / は / が / を / って / など ... ) に
  続くときは内側を文末としない (fast-bunkai / bunkai の
  IndirectQuoteException を参考にした純 Lua 実装。外部ランタイム不要)。

operator-pending の `)` / `(` にも対応する。`d)` / `c(` / `y2)` のように
オペレータと組み合わせて使える (範囲の確定は nvim-spider の setEndpoints
経由)。

>lua
    vim.keymap.set("o", ")", function()
        require("bunsetsu._commands.sentence").operator_next_end(vim.v.count1)
    end, { desc = "Next sentence end" })
    vim.keymap.set("o", "(", function()
        require("bunsetsu._commands.sentence").operator_prev_end(vim.v.count1)
    end, { desc = "Previous sentence end" })
<

テキストオブジェクト (選択範囲の確定は spider 経由):
    is / as   カーソル下の文 (内側 / 外側。内側は文末文字を含まない)
    iW / aW   カーソル下の文節 (外側は後続の空白を含める)

>lua
    local textobj = require("bunsetsu._commands.textobj")
    vim.keymap.set({ "x", "o" }, "is", function() textobj.sentence(false) end)
    vim.keymap.set({ "x", "o" }, "as", function() textobj.sentence(true) end)
    vim.keymap.set({ "x", "o" }, "iW", function() textobj.phrase(false) end)
    vim.keymap.set({ "x", "o" }, "aW", function() textobj.phrase(true) end)
<

9. Lua API                                                *bunsetsu-api*

require("bunsetsu") で公開している関数。

pattern([{mode}])             spider 用カスタムパターン関数を返す。
                              設定からバックエンドを自動選択する
                              (vibrato > vaporetto > TinySegmenter)。
                              mode: "word" | "bunsetsu" (省略値)。

vibrato_pattern([{mode}])     Vibrato 版の境界関数を返す。
vaporetto_pattern([{mode}])   Vaporetto 版の境界関数を返す。

next_sentence_end([{count}])  次の文末へ移動する。
prev_sentence_end([{count}])  前の文末へ移動する。
                              戻り値: 移動したか (boolean)。|bunsetsu-sentence|

full_segments()               全文モードの segment 一覧
                              ({ lnum, col, colend, idx, text }) を返す。

highlight([{enabled}])        品詞ごとのアンダーライン表示をトグルする
                              (Vibrato)。

lemma_under_cursor()          カーソル下の語の
                              { surface, lemma, reading, pos } を返す。
                              ASCII は cword、日本語は Vibrato で分割する。

lemma({surface})              指定語の辞書形を UniDic TSV
                              (lemma.dict_path) から引く。未設定・未登録時は
                              nil。

split_lines({line1}, {line2}) 指定範囲を分かち書きして置換する
                              (:BunsetsuSplit 相当)。

models()                      利用可能なバックエンド名の配列を返す
                              (tinysegmenter は常に含まれる)。

================================================================================
10. 全文モード                                          *bunsetsu-full*

バッファ全体を事前に分節化し、行単位でキャッシュする。
編集時は変更行のみ再計算するため、大きなバッファでも移動がブロックしにくい。
undo/redo や行数変化を検出した場合は全行を再処理する。

`bunsetsu.setup()` が autocmd (BufReadPost / TextChanged 等) を設定し、
バックグラウンドでキャッシュを更新する。日本語を含まないバッファでは
autocmd の処理をすべてスキップするため、コード編集のオーバーヘッドは
ほぼゼロ。
